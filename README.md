# VectorDB - Neural Search Engine

A lightweight, custom Vector Database built from scratch in Java utilizing the Javalin framework for backend services and a web-based user interface.

## 🚀 Features
* **Custom Indexing:** Implements high-performance nearest-neighbor search using **HNSW** (Hierarchical Navigable Small World) and **KD-Tree** structures.
* **REST API Endpoints:** Powered by **Javalin** to handle document loading, tokenization, and vector querying.
* **Interactive UI:** A dark-themed web interface to easily visualize search queries and vector matches.

## 🛠️ Tech Stack
* **Backend:** Java (Maven)
* **Web Framework:** Javalin
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
